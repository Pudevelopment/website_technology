## Content

This website contains the following parts:

- a fully functional login system
- a website with the informations about cable ways, slope vehicles and snowmaker
- the possibility to add more informations to the website via the login system
- a fully external stylesheet
- a database with multiple tables

> [!TIP]
> This web application is **not** optimized for mobile devices

## How to use this website

1. You need a webserver with **Apache and a database** (e.g. Mariadb)
2. Add the folder `Website` to your webserver
3. Edit `config_example.php` with your information
3. Add `users.sql.gz`, `Seilbahndaten.sql.gz`, `PistengeraeteDaten.sql.gz` and `BeschneiungsDaten.sql.gz`
4. Configure your Server ports `80` (http) and `443` (https) to access your website
